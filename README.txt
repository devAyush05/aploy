# Sorry Priya 💗

A romantic glassmorphism apology website made with plain HTML, CSS and JavaScript.

## Files
- `index.html` — landing page
- `apology.html` — second page
- `style.css` — complete styling + animations
- `script.js` — floating hearts + interactions

## Run
Just open `index.html` in a browser, or use VS Code Live Server.

## Online GIFs
The website uses embedded GIFs from GIPHY and Tenor. Internet is required for those GIFs to load.
